# MARMOR — Die Kunst des Steaks

Eine moderne, deutschsprachige Website über Steak: Cuts, Garstufen und Zubereitung.

## Starten

Die Seite ist statisch. Einfach `index.html` im Browser öffnen oder lokal serven:

```bash
python3 -m http.server 4173
```

Dann [http://localhost:4173](http://localhost:4173) öffnen.

## Inhalt

- 12 Steakarten mit Filter (Premium, Klassiker, Grill)
- Detailansicht je Cut
- Interaktive Garstufen
- Tipps zur Zubereitung
- Dry Aged vs. Wet Aged
